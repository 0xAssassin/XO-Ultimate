# Contributing

## Report a bug

Open an issue with:

- Device and operating system.
- Browser or Android WebView version, if known.
- Website or Android APK, and app/release version.
- Steps to reproduce the problem.
- Expected and actual behavior.
- A screenshot or recording if helpful; remove personal information first.

## Suggest a feature

Explain the feature, who it helps, and how it should behave.

## Submit a change

Keep changes focused and describe what changed and how you checked it. Confirm that the game works at phone width and on desktop, that selection cards remain centered, and that the allowed board mapping remains correct. For audio changes, check touch activation, mute controls, and background/resume behavior. For downloads, check that the main game page stays open.

Do not commit signing keys, passwords, tokens, credentials, or generated Android build outputs. Do not replace the original release signing identity when preparing an update.
